Botkin MCP — свой Claude Desktop видит твои данные

Для тех, у кого на компьютере уже есть Claude Desktop: подключаешь коннектор — и Claude в любом чате видит твои данные из Botkin, а не общие слова.

Что это

MCP (Model Context Protocol) — открытый стандарт, по которому AI-приложение вроде Claude Desktop подключается к внешним источникам данных. Botkin MCP — наш коннектор, он отдаёт Claude:

  • питание за любой период (КБЖУ, продукты, калории)
  • вес, % жира, давление, биомаркеры
  • тренировки и активность
  • журнал добавок и лекарств

Приватные файлы (КПТ-дневник, сканы анализов, которые ты не грузил в Botkin, файлы медприборов) коннектор не трогает вообще — для них в Claude Desktop есть свой встроенный Filesystem-коннектор. Claude видит оба источника разом, поэтому и получается гибридная приватность: серверное — через Botkin, личное — мимо него.

Что с этим можно делать

«какие у меня тренды веса за последний месяц?»
«что я ел вчера, посчитай средний КБЖУ за неделю»
«запиши что я съел омлет с тостом на 450 ккал»
«посмотри давление за 2 недели — есть паттерн?»
«прочитай мой КПТ-дневник и сравни с днями, когда я ел больше нормы»

Последний пример — вся суть: Botkin MCP видит «2800 ккал 18 мая», Filesystem-коннектор видит личную запись за то же число — и Claude сопоставляет их сам, а дневник при этом никуда на сервер не уходит.

Как подключить

Шаг 1 — получи токен в боте. В чате с @Botkin_md_bot напиши /connect_mcp. Бот спросит, какой доступ нужен: полный (чтение и запись — для своего личного Claude) или только чтение (можно отдать врачу или ещё кому-то — он увидит данные, но не сможет ничего изменить). Выдаст токен вида pat_... — это личный ключ, не публикуй его. Управлять токенами (посмотреть, отозвать) — командой /my_connections.

Шаг 2 — скачай коннектор. Файл botkin-connector.mcpb — в Releases репозитория или спроси у Александра.

Шаг 3 — установи в Claude Desktop. Settings → Extensions → «Install extension» → выбери скачанный .mcpb. Вставь токен из шага 1 в поле «Токен Botkin». Поле «Сервер API» не трогай — там уже правильный адрес.

Шаг 4 — проверь. В новом чате напиши «покажи мой профиль из Botkin» — Claude ответит твоими реальными данными.

Если .mcpb недоступен — вручную

Открой claude_desktop_config.json (macOS: ~/Library/Application Support/Claude/claude_desktop_config.json, Windows: %APPDATA%\Claude\claude_desktop_config.json) и добавь:

{
  "mcpServers": {
    "botkin": {
      "command": "python",
      "args": ["/путь/к/scripts/mcp/botkin_pat_mcp.py"],
      "env": {
        "BOTKIN_PAT": "твой-токен-из-/connect_mcp",
        "BOTKIN_API_BASE": "https://health.orangegate.cc"
      }
    }
  }
}

Нужен Python 3.11+ и pip install mcp requests. После сохранения — полностью выйди из Claude Desktop (Cmd+Q) и открой заново.

Если что-то не работает

  • Claude не видит инструменты Botkin — не перезапустил приложение целиком (Cmd+Q, не просто закрыть окно).
  • «PAT недействителен» — токен отозван или неверный. Выпусти новый: /connect_mcp.
  • «Токен только для чтения» — просишь что-то записать, а токен ro. Выпусти rw-токен.
  • Хочешь поделиться данными с врачом — /connect_mcp → «только чтение» → отдай строку токена.
  • Боишься, что токен утёк — /my_connections → отозвать. Старый перестаёт работать сразу.

Каждый токен видит данные только одного пользователя — на уровне базы данных, а не только в коде. rw-токен — для себя, ro — для тех, кому просто показываешь.
